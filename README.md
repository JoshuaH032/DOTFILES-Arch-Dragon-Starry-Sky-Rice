# 🌌 Arch-Dragon — Starry Sky Rice

> “Every command paints another star.”

A minimalist yet expressive Hyprland rice built for elegance, clarity, and flow; designed to feel like working beneath a calm night sky.  
This setup blends intentional design with Arch Linux’s bleeding-edge nature, themed around serenity and performance.

---

### 🧩 Components
- **WM:** Hyprland (Wayland)
- **Bar:** Waybar (JSONC + CSS)
- **Terminal:** Kitty (Rose Pine Dawn)
- **Font:** Noto Sans Mono / JetBrains Mono
- **Cursor:** RosePineDawn-Linux (24px)
- **Shell:** Bash
- **Theme:** Starry Sky (cool tones + minimal blur)

---

### ⚙️ Installation
Clone the repository:
```bash
git clone git@github.com:JoshuaH032/DOTFILES-Arch-Dragon-Starry-Sky-Rice.git

# Move configs into your .configs folder:

cp -r DOTFILES-Arch-Dragon-Starry-Sky-Rice/.config/* ~/.config/

# Reload Hyprland

hyprctl reload
